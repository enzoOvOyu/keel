# 资产自定义视图（WP-2.2 / FR-3.3）

2026-10-27：源码增量，迁移081及新用例 **NOT_RUN**，未部署。它只投影已有库存，不触发采集，不提供G1/配置合规或硬件验收结论。

资产页“资产自定义视图”按需加载编辑器。列可选择资产登记、Redfish报告或网络NOS/硬件快照；新增、删除与调整列顺序，按列排序及分组。个人视图只对本人可见；团队视图对当前项目成员共享。团队视图由原作者或Admin/DL编辑，创建/编辑团队视图还需Admin/DE/DL/SRE，普通成员可保存个人显示偏好。平台管理员不因此越过他人个人视图的可见性过滤。

保存产生不可变revision；视图ID、项目、原作者与可见范围不可改，分享使用“复制为新视图”保存团队副本。保存请求使用稳定客户端ID和expected_version CAS，精确重复返回原revision；旧版本编辑与使用另一revision的数据/CSV请求拒绝。项目归档/交付后不再修改显示模板，历史仍可读取。作用域、会话/当前成员权限、CSRF/Origin和审计复用现有平台。

## 字段与条件着色

支持有界JSONPath子集：`$`、`.property`、`["quoted key"]`/`['quoted key']`、`[index]`、数组`[*]`。不执行脚本、过滤表达式、递归下降、切片、对象通配符；不声称完整JSONPath标准实现。路径≤512字节/16段；单列≤32匹配/4096字节，最多16列。

- `asset` 根是资产登记元数据，例如`$.hostname`、`$.rack`、`$.state`、`$.model_version_id`。
- `redfish` 根是原BMC结构化报告，例如`$.resources[*].data.BiosVersion`或`$.resources[0].data['@odata.type']`。资源顺序并非永久身份，长期显示优先选择属性通配投影，原始路径/资源ID留在来源证据中。
- `network` 根是FR-0保留的规范化交换机快照，例如`$.nos`、`$.ports[*].name`，不假设服务器有网络设备快照。

条件着色只引用`baseline_key`，基线取当前项目参数目录覆盖全局目录，附目录ID/updated_at/value/state。项目退役的键不回退到全局值；缺失、退役、超限或非标量基线保持unknown。没有代码内固件版本或凭空生成的“正式配置基线”。这是当前有效目录值的显示比较，后置完整项目模板绑定与正式配置一致性仍按其工作包接入。

服务器保留采集ID/hash/origin/时间、身份匹配、资产version/最新BOM与保鲜状态；失败、partial、sim、陈旧和过大报告不被着色成通过。交换机来源`device`与`protocol_fixture`分开，按原运行有效期和网络BOM批次判断；未确认来源保持unknown。字段缺失不会填0/默认固件，值超限整体该单元格标记projection_limit。原始源文档超过2MiB时明确source_limit，不静默截断。视图不是重新采集或门禁证据。

## 范围、导出与接口

整个视图当前最多200个服务器/交换机目标，先全范围投影、分组/数值排序，再分页；超200整次拒绝，不导出仅当前页。该上限是本增量的资源界限，不能视为完成更大Fleet规模验收。基线与原观测在同一只读repeatable-read事务读取，摘要包含所用视图/事实/基线与来源状态。

- `GET /api/v1/projects/:id/asset-views`分页列出本人/团队模板；`GET .../:viewId`读取当前版本。
- `PUT .../:viewId`：32位hex稳定ID；expected_version=0创建，后续CAS追加版本；name/visibility/definition/reason受限。
- `GET .../:viewId/data?version=N&page=1&page_size=20`：精确版本的当前保留证据投影。
- `GET .../:viewId/export.csv?version=N`：完整有界范围CSV，包含来源ID/hash、状态、条件结果与目录版本；单元格及标题防电子表格公式注入，保留缺失/模拟/陈旧标记。

浏览器可导出可分享的视图定义JSON；分享团队副本不发送外部消息。界面沿用shadcn/ui及现有全局字体/语义颜色，无自动设备轮询；到期在本地移除有效着色，手动刷新重新取证据。结果是一次带evaluated_at的读取，不提供持续监控。

新增解析/投影上限/禁止可执行路径、目录着色/陈旧模拟/缺失、排序分组/稳定缺失排序、CSV公式/版本来源及隔离PG个人隐私、团队权限、精确重复/CAS/不可变历史与跨项目读取用例，全部NOT_RUN。尚需重大里程碑集中验证、真实型号/交换机字段适配、200台性能与UI可用性验证，WP-2.2/FR-3保持partial。
