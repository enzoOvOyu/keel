# Intel One Mono

Unmodified web fonts from Intel release V1.4.0: https://github.com/intel/intel-one-mono/tree/V1.4.0/fonts/woff2

SIL Open Font License 1.1: see OFL.txt. SHA256SUMS pins the bundled files. Served locally; no external runtime font requests.

Latin text uses Intel One Mono; unsupported glyphs, including Chinese, use the configured system fallback. Do not copy font-family stacks into components: use the global typography tokens.
