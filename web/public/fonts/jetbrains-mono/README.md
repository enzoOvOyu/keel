# JetBrains Mono

Official JetBrains/JetBrainsMono v2.304, commit `cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9`.
Source: https://github.com/JetBrains/JetBrainsMono/tree/cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9

Unmodified Regular (400), Medium (500), SemiBold (600), Bold (700) WOFF2 files, bundled under the included SIL OFL 1.1. SHA256SUMS records each asset. Loaded locally with font-display: swap; no runtime CDN. Chinese glyphs use the shared system fallback stack. Ligatures are disabled to keep operational identifiers literal. The former Intel assets remain as historical files, without active CSS loading.
